# F-012 SPLINE scope

Status: implementation candidate, **not certified**. The immutable 133-row score remains unchanged until the full AutoCAD/browser/read-back/oracle matrix passes.

## Implemented in the first typed wave

- Separate Fit and Control Vertices document semantics.
- Open CV splines with degree 1 through 10, optional positive rational weights, and clamped knots.
- Open exact fit-point construction with Chord, Square root and Uniform parameterization; the three-point case remains cubic.
- Non-zero Fit Tolerance changes evaluated geometry, reparameterizes the resulting knot vector and keeps every original Fit point within the requested bound. AutoCAD's exact proprietary approximation control polygon is still an open equivalence item, so this is not presented as complete parity.
- Registry aliases `SPL` and `SPLINE`, one atomic IndexedDB operation and global Undo/Redo.
- Fit points, tolerance and endpoint tangents preserved through production DXF import/export and `.kdraw`.
- MOVE/COPY/ROTATE/SCALE/MIRROR and block-affine transforms keep fit metadata coherent; a partial CV stretch deliberately converts the definition to CV data instead of retaining stale fit points.
- Chromium read-back covers Fit and CV commits, IndexedDB, DXF via `dxf-parser`, `.kdraw`, Undo/Redo and zero console errors.
- Physical canvas picks drive an incremental preview through the same registry/kernel predicate as final commit; command-local Undo removes only the latest point and the final object is one atomic operation.
- Closed Fit and CV workflows emit periodic output; closed Fit interpolates every input point with an exact C2 seam.
- Open Fit workflows accept explicit start/end tangent vectors and preserve them through geometry, document storage and DXF read-back. Tangents are normalized to the AutoCAD/DXF unit-vector contract; the physical start prompt stores `endpoint - pickedPoint`, while the end prompt stores `pickedPoint - endpoint`. Command-local Undo removes the first tangent without mutating the document.
- SPLINEDIT is wired end-to-end for Reverse, Fit Add/Delete/Move, Fit Tangents/Tolerance/Knot properties, Purge, CV Move/Weight and Fit/CV Open/Close. Immediate edits and a repeated Stage/command-local Undo/one atomic Commit workflow both use the same registry/kernel predicate.
- Production read-back covers open Fit with tangents, closed periodic Fit, rational CV, SPLINEDIT, DXF raw groups, strict importer, `dxf-parser`, `.kdraw` and Undo/Redo.
- Pinned LibreCAD 2.2.1.5 renders the exact production DXF as vector output and FreeCAD 1.1.3/OCCT independently rebuilds all six evaluated NURBS representations; both remain `certificationAuthority:false` secondary oracles.
- AutoCAD 2024 Core Console runs a real scratch command workflow for Fit creation, Reverse, Close, Open and command-local Undo. The report is authoritative only for this explicit subset and does not certify F-012 as a whole.
- `SPLINE Object` atomically replaces one selected open PEDIT spline-fit polyline with a new-handle degree-3 CV spline, preserving its four control vertices, properties and clamped knot vector. The same source deletion/result creation is proven in AutoCAD Core, Chromium, IndexedDB Undo/Redo, production DXF and FreeCAD/LibreCAD secondary read-back.
- AutoCAD Core additionally measures zero/non-zero tolerance control points, changed knot vectors, closest-point deviations and a mirrored geometry fixture. The owned Desktop matrix independently proves command creation, property preservation, Reverse, Open/Close and both command-local and global Undo/Redo for its declared subset.
- `SPLINEDIT Convert to Polyline` now has a real linear `LWPOLYLINE` production path: integer precision `0…99` monotonically refines an adaptive quarter/midpoint chord-error approximation, each active knot span is retained, the source is deleted, a new handle is created, properties survive, and the whole replacement is one atomic Undo/Redo operation. The precision-10 path is proven through the visible browser, IndexedDB, production DXF, strict/dxf-parser read-back and `.kdraw`; AutoCAD Core independently proves the corresponding `PLINECONVERTMODE=0` source-delete/new-handle behavior and a 41-vertex, sub-unit result for its fixture.
- `SPLINEDIT Fit Kink` projects the picked model point onto the evaluated Fit spline, inserts the new knot to degree multiplicity without changing the curve, preserves the handle/properties and purges Fit data to a CV definition. AutoCAD Core independently proves the same handle, `5 → 0` Fit count, cubic knot multiplicity 3 and zero deviation across 21 samples; Chromium proves physical canvas pick, preview, command-local Undo, atomic commit, production DXF/KDRAW1 and global Undo/Redo. FreeCAD reconstructs the refined NURBS and LibreCAD renders the exact production output as secondary oracles.
- `SPLINEDIT Refine/Add` projects a physical model pick onto an open CV spline and inserts exactly one interior knot without changing the curve. `Refine/Elevate order` raises degree/order in homogeneous space while preserving rational geometry. AutoCAD Core proves the same handle, cubic `4 CV / 8 knot → 5 CV / 9 knot` Add result, order-5 `degree 4 / 7 CV / 12 knot` result and zero deviation across both 21-sample comparisons. Kuubiku golden tests match AutoCAD's exact non-rational control polygons, Chromium proves staged Add→Elevate with command-local Undo and one atomic commit, production DXF/KDRAW1 read-back is strict, and FreeCAD reconstructs the degree-4 output.
- The owned AutoCAD 2024.1.2 desktop probe now supplies the graphical subentity evidence that Core Console cannot. `CVSHOW` plus exact CV picks prove both the single-knot middle case and an open cubic two-knot matrix across all six CV indices, including both endpoints: AutoCAD removes the picked CV and the interior knot nearest that CV's Greville abscissa while preserving handle, layer and appearance. Kuubik uses the same typed rule, renders the selected spline's CV grips, accepts a physical grip click, stages preview without a document mutation and commits one atomic Undo/Redo operation. Production DXF/KDRAW1, strict importer, `dxf-parser`, LibreCAD rendering and FreeCAD/OCCT reconstruction all read the four-CV output back.
- The CV Delete desktop matrix now also proves rational weight-index retention, every CV across a repeated interior knot, all four minimum cubic CVs with AutoCAD's `degree 3 → 2` reduction, all five CVs of an open quadratic spline (including the exact Greville tie resolving to the later knot), and a closed-periodic graphical deletion. Kuubik mirrors these rules, rebuilds the periodic extended knot sequence from AutoCAD's compact sequence so the C2 seam remains exact, and exercises minimum/quadratic/periodic variants through physical browser grip clicks. The production DXF/KDRAW1 fixture contains separate rational/repeated, minimum-degree, periodic and quadratic outputs; LibreCAD renders all 12 entities and FreeCAD/OCCT reconstructs all 11 NURBS entities as non-authoritative secondary evidence.

## Remaining before score 1.00

- Exact AutoCAD-equivalent non-zero Fit Tolerance approximation geometry (the current implementation enforces the same tolerance bound and changed-knot semantics, but its control polygon is not yet identical).
- Object conversion variants beyond the now-proven open four-CV PEDIT spline-fit polyline case, including eligible closed and quadratic sources.
- Remaining SPLINEDIT matrix: Join. CV Delete still needs minimum periodic/linear and additional degenerate desktop variants, but its principal open cubic/quadratic, rational, repeated-knot, degree-reduction and periodic paths are now measured and implemented. CV Add/Elevate still need the closed/periodic and degenerate desktop variants before the complete F-012 row can be certified. Convert to Polyline still needs AutoCAD-exact precision-to-vertex distribution, `PLINECONVERTMODE=1` arc-segment behavior, DELOBJ retention variants and the rest of its closed/rational/degenerate matrix before that option is complete.
- Locked/hidden-layer and degenerate geometry live matrix.
- Remaining owned AutoCAD 2024.1.2 desktop live-command matrix and independent 0 P0 / 0 P1 review.

# Reio minimaalse 2D CAD-i valik

Valikuleht asub arenduskeskkonnas aadressil `http://127.0.0.1:5190/scope.html`.

1. Ava funktsioonigrupp.
2. Märgi ainult päriselt vajalikud F-read.
3. Lisa soovi korral lokaalne märkus.
4. Vajuta **Ekspordi JSON**.
5. Anna fail `kuubik-draw-reio-scope-v1.json` arendusplaani koostamiseks.

Valik salvestub automaatselt brauseri lokaalsesse salvestusse. Vabateksti GitHubi ega serverisse ei saadeta. Kõik checkboxid on esimesel avamisel tühjad. Soovitusmärgis on orientiir, mitte automaatne valik.

Uue minimaalse scope'i 100% tähendab, et iga valitud F-rida on AutoCAD 2024.1.2 võrdluses skooriga `1,00`. Algne 133-realine audit jääb muutmata võrdlusmaterjaliks. Valimata tööriistad jäävad hiljem CAD-i ribbonis nähtavaks, kuid keelatud olekusse.

`reio-minimal-scope-v1.json` is the public, technical source of truth for the
first focused Kuubik Draw release.

- Selected scope: 94 of the unchanged 133 AutoCAD 2024.1.2 2D audit rows.
- Completion target: every selected row is independently evidenced at `1.00`.
- Unselected commands remain visible but disabled in the AutoCAD-familiar UI.
- The original 133-row audit, row identifiers, weights, and baselines remain
  unchanged and continue to be reported separately.
- Local notes and the export timestamp are intentionally excluded.

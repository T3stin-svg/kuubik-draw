# Contributing

Contributions are licensed under `GPL-2.0-only` and require a Developer
Certificate of Origin sign-off:

```text
Signed-off-by: Your Name <you@example.com>
```

Before submitting:

1. do not include customer drawings, credentials, `.env` files or Autodesk
   proprietary assets;
2. record every upstream-derived idea in `upstream-provenance.json`;
3. keep AutoCAD behaviour tests separate from LibreCAD/FreeCAD oracle reports;
4. run `npm run check`;
5. never raise a parity score without AutoCAD live evidence and output read-back.
